# Código de conducta

## En resumen

Trata a la gente con respeto. Critica el código, no a las personas.

## Qué se espera

- Comentarios técnicos concretos y argumentados.
- Aceptar que otra persona puede tener contexto que tú no tienes.
- Dar por hecha la buena intención hasta que se demuestre lo contrario.

## Qué no se acepta

- Ataques personales, insultos o desprecio hacia quien pregunta.
- Comentarios sobre características personales de nadie.
- Acoso, público o privado.
- Publicar información privada de terceros.

## Aplicación

Quien mantiene el proyecto puede editar, ocultar o borrar comentarios, commits
o issues que incumplan lo anterior, y bloquear a quien insista.

Si ves algo que no debería estar ahí, escribe en privado a través del perfil de
GitHub de quien mantiene el repositorio. Se tratará con discreción.
